Zerodha Clone 

## Live Demo

🔗 https://zerodha-clone-il9b.vercel.app

📌 Overview

A full-stack Zerodha Clone that simulates a real-world stock trading platform. Users can explore stocks, 
manage their portfolio, and perform buy/sell operations in a seamless UI.

🛠️ Tech Stack

Frontend: React.js, CSS
Backend: Node.js, Express.js
Database: MongoDB

✨ Key Features

> Secure User Authentication (JWT based Login/Signup)
> Real-time Stock Dashboard UI
> Buy & Sell Stocks functionality
> Portfolio Tracking System
> Fully Responsive Design

⚙️ Installation & Setup

git clone https://github.com/surjeetsingh-tech/zerodha-clone.git
cd zerodha-clone
npm install
npm start

/frontend   → React UI
